=== ИНСТРУКЦИЯ ПО ЗАПУСКУ В TERMUX ===

1. ПОДГОТОВКА ОКРУЖЕНИЯ
Выполните эти команды сразу после клонирования:
pkg update && pkg upgrade
pkg install openjdk-17 dos2unix git

2. ИСПРАВЛЕНИЕ ОКОНЧАНИЙ СТРОК (ВАЖНО!)
Если проект создавался на Windows, скрипты могут не запуститься из-за CRLF.
Выполните:
dos2unix gradlew run.sh BUILD_PROJECT.sh
chmod +x gradlew run.sh BUILD_PROJECT.sh

3. СБОРКА ПРОЕКТА
Соберите приложение с помощью Gradle Wrapper:
./gradlew installDist

4. ЗАПУСК (ЛР №4 - ВАРИАНТ 5)
Запуск сервера с динамическим пулом потоков:
./run.sh 3 1

Где:
 3 - Режим сервера (Thread Pool / Lab 4)
 1 - Протокол TCP

5. ПРОВЕРКА РАБОТЫ
Вы можете подключиться к серверу из другого окна Termux:
pkg install telnet
telnet localhost 9999

=== СОВЕТЫ ПО GIT ===

Как полностью очистить проект и синхронизироваться с облаком:
1. git reset --hard HEAD      (удалить изменения в файлах)
2. git clean -fd              (удалить новые/лишние файлы)
3. git fetch origin           (обновить список веток с сервера)
4. git checkout ИМЯ_ВЕТКИ     (перейти на нужную ветку)
5. git pull origin ИМЯ_ВЕТКИ  (скачать свежий код для ветки)

Как перенести коммиты из одной ветки в другую:
1. git checkout main                   (перейти в ветку, куда случайно сделали коммит)
2. git checkout -b temp-branch          (создать временную ветку из текущего состояния)
3. git checkout main                   (вернуться на main)
4. git reset --hard HEAD~2             (откатить main на 2 коммита назад)
5. git push origin main --force        (принудительно обновить main в облаке)
6. git checkout termux-fix             (перейти в целевую ветку)
7. git merge temp-branch               (слить изменения из временной ветки)
