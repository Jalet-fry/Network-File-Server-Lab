=== ШПАРГАЛКА ДЛЯ СДАЧИ ЛАБОРАТОРНЫХ РАБОТ ===

1. ПОДГОТОВКА (ПЕРЕД СДАЧЕЙ)
На ноутбуке (Windows): ipconfig -> узнать IPv4 (например, 192.168.1.10)
В Termux:
  git fetch origin
  git checkout termux-fix
  git reset --hard origin/termux-fix
  ./gradlew installDist

-----------------------------------------------------------
ЛАБОРАТОРНАЯ №1 (TCP, Последовательный сервер)
-----------------------------------------------------------
Сервер (Windows): run.bat 1 1
Клиент (Termux):  ./run.sh 2 1 8888 <IP_НОУТБУКА>

-----------------------------------------------------------
ЛАБОРАТОРНАЯ №2 (UDP, Надежная доставка)
-----------------------------------------------------------
Сервер (Windows): run.bat 1 2
Клиент (Termux):  ./run.sh 2 2 8888 <IP_НОУТБУКА>

-----------------------------------------------------------
ЛАБОРАТОРНАЯ №4 (Thread Pool, Вариант 5)
-----------------------------------------------------------
Сервер (Windows): run.bat 3 1
Клиент (Termux):  Запустить 2-3 клиента одновременно из разных окон Termux:
                  ./run.sh 2 1 8888 <IP_НОУТБУКА>

-----------------------------------------------------------
ДЕМОНСТРАЦИЯ РАБОТЫ С ФАЙЛАМИ
-----------------------------------------------------------
- Сервер (Windows) хранит файлы в: /files-server/
- Клиент (Termux) хранит файлы в:  /files-client/ (внутри папки проекта)

А. СКАЧИВАНИЕ (DOWNLOAD): Termux забирает файл с Windows
1. На ноутбуке в /files-server/ положи файл (например, test_from_server.txt).
2. В клиенте Termux выполни команду: DOWNLOAD test_from_server.txt
3. Результат: Файл появится в /files-client/ на телефоне, в консоли увидишь скорость.

Б. ЗАГРУЗКА (UPLOAD): Termux отправляет файл на Windows
1. В Termux положи файл в папку клиента, например:
   cp /sdcard/Download/my_photo.jpg ~/Network-File-Server-Lab/files-client/
2. В клиенте выполни команду: UPLOAD my_photo.jpg
3. Результат: Файл появится в /files-server/ на ноутбуке.

В. ПРОВЕРКА ФАЙЛОВ В TERMUX
Чтобы посмотреть, какие файлы лежат в папке клиента на телефоне, выйди
из программы (Ctrl+C) и введи:
   ls -l files-client/

-----------------------------------------------------------
ПОЛЕЗНЫЕ КОМАНДЫ TERMUX:
- chmod +x run.sh gradlew    (если не запускается)
- dos2unix run.sh            (если ошибка "bad interpreter")
- ./gradlew clean            (если сборка глючит)
