# Ответы на вопросы к Лабораторной работе №6

## 1. В чем отличие многоадресной и широковещательной передачи?
*   **Широковещательная передача (Broadcast):** Пакет отправляется **всем** узлам в данном сегменте сети (подсети). Каждый узел получает и обрабатывает пакет на сетевом уровне.
*   **Многоадресная передача (Multicast):** Пакет отправляется **группе** заинтересованных узлов. Узлы должны явно "подписаться" на группу (join group). Пакет обрабатывается только теми узлами, которые состоят в группе; остальные узлы отбрасывают его на уровне сетевой карты или драйвера.

## 2. Как формируется широковещательный адрес?
Широковещательный адрес (Limited Broadcast) для всей сети — `255.255.255.255`.
**Направленный широковещательный адрес (Directed Broadcast)** формируется путем установки в 1 всех бит в части адреса, отвечающей за хост (host part), в соответствии с маской подсети.
Например: IP `192.168.1.5` с маской `255.255.255.0` (24 бита) -> Broadcast `192.168.1.255`.

## 3. Какие диапазоны адресов многоадресной передачи существуют? Каково их назначение?
Диапазон IPv4: `224.0.0.0` – `239.255.255.255` (Класс D).
*   `224.0.0.0` – `224.0.0.255`: Зарезервировано для протоколов маршрутизации и управления в локальной сети (например, `224.0.0.1` — все узлы, `224.0.0.2` — все маршрутизаторы).
*   `224.0.1.0` – `238.255.255.255`: Глобальные (интернет) Multicast адреса.
*   `239.0.0.0` – `239.255.255.255`: Адреса с ограниченной областью распространения (Organization-Local Scope), аналоги приватных IP адресов.

## 4. Какие есть механизмы ограничения области распространения многоадресных пакетов?
1.  **TTL (Time-to-Live):** Маршрутизаторы уменьшают TTL. Если TTL=1, пакет не выйдет за пределы локального сегмента.
2.  **Административные границы (Scoping):** Использование диапазона `239.x.x.x`, который маршрутизаторы не должны выпускать за пределы организации.
3.  **IGMP Snooping:** Механизм на коммутаторах L2, который позволяет отправлять Multicast трафик только в те порты, где есть подписчики группы.

## 5. Какова область распространения широковещательных пакетов?
Широковещательные пакеты обычно **не выходят за пределы локального сегмента сети (Broadcast Domain)**. Маршрутизаторы по умолчанию не пересылают широковещательный трафик между разными подсетями, чтобы предотвратить "широковещательные штормы".
