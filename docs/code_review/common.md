# 🛠️ Пакет sspoirs.common

Этот пакет содержит общие утилиты и константы, используемые всеми частями проекта (TCP, UDP, Thread Pool).

### 1. Command.kt
**Роль:** Перечисление (Enum) всех поддерживаемых команд протокола.
- Преобразует строковые команды (например, "LS" или "EXIT") в типизированные объекты `Command`.
- Поддерживает маппинг синонимов (`LIST` -> `LS`, `EXIT` -> `CLOSE`).

### 2. Constants.kt
**Роль:** Глобальный конфигурационный файл проекта.
- **Сетевые настройки:** Дефолтный порт (8888), размер буфера (8 КБ).
- **UDP:** Размер пакета (1400 байт) для исключения фрагментации MTU, таймауты и количество повторов.
- **Thread Pool (ЛР4):** Границы пула потоков (Nmin=2, Nmax=10) и Idle Timeout (60с).
- **Пути:** Названия папок для хранения файлов сервера и клиента.

### 3. NetworkUtils.kt
**Роль:** Низкоуровневые операции с потоками ввода-вывода.
- `readLineBuffered`: Читает байты из `InputStream` до символа `\n`. Критично для TCP, чтобы правильно определять границы команд.
- `copyStream`: Универсальная функция передачи файлов.
    - Реализует отображение прогресса в консоли.
    - **Urgent Data (OOB):** Каждые 1.5 секунды отправляет байт прогресса через `socket.sendUrgentData()`.
    - Считает и выводит битрейт (скорость) после завершения.

### 4. ReliableUdp.kt
**Роль:** Реализация "Надежного UDP" поверх стандартного `DatagramSocket`.
- **Формат пакета:** [Тип (1б) | SEQ (4б) | Payload].
- **Типы пакетов:** 0 - Данные, 1 - ACK, 2 - Команда.
- `sendReliable`: Отправляет данные и ждет ACK. Если ACK не пришел за `UDP_TIMEOUT`, делает повтор (`MAX_RETRIES`).
- `receive`: Принимает пакеты, автоматически фильтруя дубликаты и отвечая на ACK для входящих данных.
- Поддерживает очередь пакетов для реализации скользящего окна в ЛР2.
