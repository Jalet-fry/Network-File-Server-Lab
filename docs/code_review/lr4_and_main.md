# 🧵 Пакет sspoirs.lr4 и Точка входа

### 1. TcpThreadPoolServer.kt (ЛР 4, Вариант 5)
**Роль:** Реализация параллельного сервера с использованием пула потоков.
- **ThreadPoolExecutor:** Сконфигурирован согласно варианту 5.
    - `corePoolSize` = `Constants.THREAD_POOL_N_MIN` (2).
    - `maximumPoolSize` = `Constants.THREAD_POOL_N_MAX` (10).
    - `keepAliveTime` = 60 секунд (лишние потоки умирают после простоя).
    - `SynchronousQueue`: Очередь с нулевой емкостью. Она заставляет пул создавать новый поток немедленно, если есть свободное место до Nmax, а не копить задачи в очереди.
- **Защита accept:** Вызов `serverSocket.accept()` обернут в блок `synchronized`. Это гарантирует, что в один момент времени только один поток из пула пытается извлечь соединение из системного бэклога (защита от Thundering Herd).
- **Dispatching:** После акцепта сокет передается в `executor.execute`, где запускается `TcpSessionHandler` из ЛР1. Это демонстрирует повторное использование кода.

### 2. Main.kt
**Роль:** Единая точка запуска приложения.
- **Парсинг аргументов:** 
    - Режим 1: Последовательный/Мультиплексный сервер.
    - Режим 2: Клиент.
    - Режим 3: Сервер с пулом потоков (ЛР4).
- **Инициализация:** Вызывает `Constants.initDirs()` для создания папок `files-server` и `files-client`.
- **Выбор протокола:** Поддерживает переключение между TCP и UDP через аргументы командной строки.
