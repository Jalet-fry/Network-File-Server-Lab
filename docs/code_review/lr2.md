# 📡 Пакет sspoirs.lr2 (Reliable UDP)

Этот пакет реализует передачу данных по протоколу UDP с гарантией доставки, имитируя поведение TCP.

### 1. ReliableUdp.kt (Находится в common, но является сердцем ЛР2)
- **Механизм ACK:** Каждому пакету присваивается Sequence Number (SEQ). При получении пакета данных принимающая сторона отправляет пакет типа ACK с этим же SEQ.
- **Таймауты и повторы:** Метод `sendReliable` блокирует выполнение до получения ACK или исчерпания попыток.
- **Оптимизация (Fast Send):** Метод `sendFast` отправляет пакет без немедленного ожидания подтверждения, что используется для реализации скользящего окна.

### 2. UdpServer.kt
- **Слушающий цикл:** Принимает пакеты и диспетчеризирует их.
- **Скользящее окно (Download):** 
    - Реализована пачечная отправка (Window). Сервер шлет группу пакетов (например, 128 штук) и ждет подтверждения только для части из них (кумулятивный ACK).
    - Если подтверждение не пришло, сервер откатывает позицию в файле (`fc.position(windowStartPos)`) и перепосылает окно.
- **Буферизация ОС:** Увеличивает `receiveBufferSize` сокета до 4–8 МБ, чтобы не терять пакеты при быстрой отправке.

### 3. UdpClient.kt
- **Интерактивный интерфейс:** Использует библиотеку JLine для автодополнения имен файлов и команд в консоли.
- **Адаптивный ACK:** В методе `receiveFileData` реализована логика: подтверждать каждый 50-й пакет в середине файла и каждый 5-й в конце, чтобы ускорить передачу, не жертвуя надежностью.
- **Поддержка докачки:** Как и в TCP, перед началом передачи клиент запрашивает список файлов и их размеры, чтобы вычислить нужный `offset`.
