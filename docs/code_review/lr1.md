# 🌐 Пакет sspoirs.lr1 (TCP и Базовая логика)

Этот пакет реализует фундамент проекта: TCP-сервер, клиент и логику обработки сессий.

### 1. TcpSessionHandler.kt
**Роль:** Основной обработчик логики взаимодействия с клиентом.
- **Интерфейс Runnable:** Позволяет запускать обработку каждого клиента в отдельном потоке (используется в ЛР4).
- **Командный цикл:** В бесконечном цикле читает строки через `NetworkUtils.readLineBuffered`, парсит их в `Command` и вызывает соответствующие методы.
- **Передача файлов (UPLOAD/DOWNLOAD):**
    - Использует `RandomAccessFile` и `seek()` для поддержки **докачки** (resume).
    - Вызывает `NetworkUtils.copyStream` для эффективной пересылки байтов.
    - Передает объект `socket` в утилиты для отправки **Urgent Data** (OOB прогресс).

### 2. TcpCommandServer.kt
**Роль:** Реализация ЛР3 (Мультиплексирование через NIO Selector).
- Использует неблокирующие сокеты (`SocketChannel`).
- **Selector:** Один поток следит за всеми активными соединениями.
- **ClientSession:** Внутренний класс для хранения состояния каждого клиента (буферы, текущий файл, статус загрузки).
- **Преимущество:** Позволяет серверу не "зависать" на одном клиенте во время долгой передачи файла, так как данные передаются порциями (чанками) по мере готовности сокета.

### 3. SimpleClient.kt
**Роль:** Интерактивный TCP-клиент.
- Поддерживает консольный ввод команд.
- Реализует логику скачивания (`DOWNLOAD`) и загрузки (`UPLOAD`) файлов с поддержкой автоматической докачки (проверяет размер локального файла и передает `offset`).
- Слушает "срочные данные" (OOB) от сервера в отдельном потоке для отображения прогресс-бара.
